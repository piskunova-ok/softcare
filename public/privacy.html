1. Общие положения

Настоящая Политика описывает, как обрабатываются персональные данные посетителей сайта SOFTCARE (далее — «Сайт»), в том числе данные, которые пользователь указывает в форме заявки на расчёт стоимости химчистки. Оператор персональных данных — [наименование оператора, ИНН, адрес].

2. Какие данные мы получаем

  • Имя (обязательное поле формы);
  • Номер телефона (обязательное поле формы);
  • Комментарий пользователя (необязательное поле, не более 500 символов);
  • Данные расчёта: состав заказа, выбранные услуги и предварительная стоимость;
  • Технические данные браузера, собираемые хостингом в обезличенном виде (cookies, IP-адрес) — на стороне платформы публикации.

Поле с honeypot используется только для отсечения автоматических запросов и не заполняется посетителями. Сайт не собирает сознательно специальные категории персональных данных, платёжные реквизиты и документы.

3. Цели обработки

  • Связь с пользователем по указанному номеру телефона для уточнения заказа;
  • Подготовка и направление предварительного расчёта стоимости услуг;
  • Исполнение требований законодательства при обработке обращений.

4. Правовые основания

Обработка выполняется на основании согласия пользователя, выраженного действием по отправке формы заявки с установленным флажком согласия, и в объёме, необходимом для заявленной цели. Согласие может быть отозвано в любой момент по обращению к оператору.

5. Способы и сроки хранения

Заявки поступают в систему приёма форм платформы публикации и хранятся там в журнале отправок. Оператор хранит данные не дольше, чем это необходимо для обработки обращения, и удаляет их по запросу пользователя либо по окончании срока хранения — [срок хранения, например 12 месяцев].

6. Передача третьим лицам

Данные передаются только платформе публикации для доставки заявки и по требованию закона. Продажа и передача данных в рекламных целях третьим лицам не осуществляются.

7. Права пользователя

  • Получить сведения об обработке своих данных;
  • Потребовать уточнения, блокирования или удаления данных;
  • Отозвать согласие на обработку;
  • Обжаловать действия оператора в уполномоченном органе.
