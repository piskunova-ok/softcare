# SOFTCARE

Калькулятор стоимости химчистки мебели
![Описание](/images/softcare-calculator.png)
## О проекте

Адаптивный веб-сайт с интерактивным калькулятором предварительной стоимости химчистки мебели. Пользователь выбирает тип и количество изделий, добавляет необходимые услуги и получает подробный расчёт стоимости.

SOFTCARE решает практическую задачу: посетитель сам выбирает мебель, количество и дополнительные услуги и сразу видит предварительный расчёт — без звонков и переписки с менеджером. В проекте реализованы адаптивная вёрстка, клиентская логика, serverless-функция, внешний каталог и автотесты.

Сайт работает в демонстрационном режиме: реальные контакты и реквизиты компании не указаны, заявки не отправляются (см. раздел «Demo mode»).

## Задача

Клиенту химчистки нужно быстро понять примерную стоимость: выбрать позиции, указать количество, добавить опции. Обычно для этого приходится ждать расчёта от менеджера вручную.

## Решение

SOFTCARE закрывает этот путь онлайн:

- интерактивный каталог мебели с фотографиями и ценами «за изделие»;
- счётчики количества для каждой позиции и для каждой дополнительной услуги;
- автоматический пересчёт и понятная детализация каждой строки;
- каталог и цены управляются через Google Sheets без правки кода;
- полностью адаптивный интерфейс с клавиатурной доступностью.

## Основные возможности

- выбор мебели из каталога и изменение количества каждой позиции (0–20);
- дополнительные услуги с собственными счётчиками: пользователь сам указывает, для скольких изделий нужна услуга;
- количество услуги ограничено количеством выбранной мебели; при уменьшении мебели количества услуг автоматически уменьшаются до допустимого максимума, при удалении всей мебели — сбрасываются в 0;
- итоговая детализация вида «Удаление сложных пятен — 2 изделия × 500 ₽ = 1 000 ₽»;
- каталог и цены из Google Sheets через серверную функцию (без OAuth и API-ключей);
- резервный демонстрационный каталог при недоступности таблицы;
- демо-форма заявки с валидацией полей — без реальной отправки данных;
- страницы «Обработка данных» (`privacy.html`) и «Демо-заявка сформирована» (`thanks.html`).

## Как работает калькулятор

1. Посетитель выбирает мебель и указывает количество.
2. При необходимости задаёт количество дополнительных услуг: «− 2 +» означает услугу на 2 изделия.
3. Стоимость услуги = цена за изделие × выбранное количество; максимум — общее количество выбранной мебели; услуги не зависят друг от друга.
4. Панель расчёта пересчитывается мгновенно: мебель, услуги, итого.
5. Блок «Ваш заказ» показывает, из чего сложилась сумма.

Формула (чистая функция `src/lib/calculator.js`, покрыта тестами):

```
база   = Σ (цена изделия × количество)
услуги = Σ (цена услуги × выбранное количество услуги)
итого  = база + услуги
```

Правила:

- количество позиции — целое от 0 до 20; отрицательные и нечисловые значения обнуляются/ограничиваются;
- услуга учитывается только при выбранной мебели;
- пустой заказ считается корректно (итог 0 ₽, кнопка заказа неактивна);
- отключённые (`Активен = нет`) и удалённые из таблицы позиции исчезают из калькулятора, ранее сделанный выбор по ним сбрасывается;
- цены не дублируются в коде — они приходят только из каталога.

## Каталог

Архитектура:

```
Google Sheets (лист «Каталог»)
   → публикация листа как CSV
      → Netlify Function читает CSV (переменная окружения CATALOG_CSV_URL)
         → JSON в браузер
            → калькулятор
```

Каталог позволяет менять ассортимент и цены без редактирования основной логики сайта.

### Подключение Google Таблицы

1. Создайте Google Таблицу, переименуйте первый лист в **`Каталог`**.
2. В первую строку вставьте заголовки (можно из `catalog-template.csv`): `ID, Тип, Название, Цена, Изображение, Активен`.
3. Заполните строки. Пример:

   | ID | Тип | Название | Цена | Изображение | Активен |
   |---|---|---|---|---|---|
   | sofa2 | furniture | Двухместный диван | 2500 | /images/item-sofa-two.webp | да |
   | stains | service | Удаление сложных пятен | 500 | | да |

4. Опубликуйте лист: **Файл → Опубликовать в интернете** → лист «Каталог» → формат **CSV (разделитель — запятая)** → скопируйте ссылку вида `https://docs.google.com/.../pub?output=csv`.
5. Добавьте ссылку в переменные окружения Netlify (`CATALOG_CSV_URL`) и перезапустите сборку. Ссылка хранится только в окружении, в код не попадает.

Требования к полям:

- **ID** — латиница, цифры, `-` и `_`; уникален; при смене ID позиция считается новой;
- **Тип** — `furniture` или `service` (допускаются «мебель»/«услуга»);
- **Цена** — число (`2500`, `2 500`, `2500,5`);
- **Изображение** — публичная https-ссылка или путь `/images/...`; пусто — аккуратная заглушка; небезопасные схемы (`http://`, `javascript:` и т. п.) отбрасываются;
- **Активен** — `да`/`нет` (или `true`/`false`, `1`/`0`).

### Кеширование и обновления

- серверная функция отдаёт каталог с `s-maxage=300` — CDN кеширует ответ примерно 5 минут;
- браузер дополнительно хранит ответ ~60 секунд;
- открытая страница сама обновляет каталог раз в 5 минут; выбранные позиции и количество сохраняются, если позиции всё ещё есть в каталоге.

Синхронизация не мгновенная: правка в таблице может появиться на сайте в течение нескольких минут.

### Резервные сценарии

Порядок при недоступности таблицы:

1. каталог из Google Таблицы;
2. последний корректный каталог из кеша браузера (`localStorage`);
3. встроенный демонстрационный каталог (`src/data/demo-catalog.js`) — сокращённый резервный набор: 4 позиции мебели и 2 услуги, это не полный актуальный каталог.

Статус над калькулятором честно сообщает о ситуации: «Каталог обновлён в HH:MM — цены из таблицы», «Свежие цены получить не удалось — показаны сохранённые данные» или «Демонстрационный каталог — Google Таблица недоступна или не подключена».

### Безопасность

- опубликованный CSV доступен всем, кто знает ссылку — не храните в таблице персональные данные и секретный контент;
- данные из таблицы не вставляются в разметку как HTML: имена и цены подставляются через `textContent`, ссылки на изображения проверяются;
- в серверной функции нет файлового состояния между запусками.

### Изображения

Путь к изображению задаётся в таблице каталога. Часть фотографий — свободные CC0-снимки, часть изображений новых позиций создана с помощью AI-генерации; состав и источники зафиксированы в `docs/источники-изображений.md`.

## Demo mode

Проект работает в демонстрационном режиме:

- на странице присутствует баннер «Демо»;
- форма заявки — интерфейсная демонстрация: валидация полей, предпросмотр расчёта, локальное сообщение «Демо-заявка сформирована. Данные никуда не отправляются»;
- введённые пользователем данные никуда не отправляются и не сохраняются;
- проект не предназначен для сбора реальных заявок.

## Технологии

- HTML5, CSS3, JavaScript — без фреймворков, баз данных и CMS;
- Vite — dev-сервер и production-сборка;
- Netlify — хостинг и serverless-функции (Netlify Functions);
- Google Sheets — внешний источник каталога (публикация листа в CSV);
- Node.js test runner (`node --test`) — автотесты.

## Тестирование

```bash
npm test        # 83 автотеста
npm run build   # production-сборка
```

Что покрыто тестами:

- расчёт: база, независимые количества дополнительных услуг, ограничение услуги количеством мебели, пустой заказ, диапазоны и некорректный ввод, отключённые позиции;
- CSV и каталог: кавычки, запятые внутри значений, CRLF, BOM, ошибки строк, фильтр «Активен», динамическое добавление позиций;
- Netlify Function: демо-каталог без переменной окружения, разбор CSV, 502 при недоступном CSV, запрет POST и не-https URL;
- демо-режим: отсутствие сетевых запросов формы, баннер, тексты подтверждения;
- валидация формы и тексты расчёта (детализация заказа).

Интерфейс дополнительно проверялся в браузере (Chrome, headless): адаптивность на основных ширинах, доступность, отсутствие ошибок JavaScript в консоли.

## Локальный запуск

```bash
npm install      # зависимости (только Vite)
npm run dev      # dev-сервер: http://localhost:5173
npm test         # автотесты
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр собранной версии
```

Локально сайт работает без Google Таблицы: если каталог с сервера недоступен, используется резервный демонстрационный каталог (это видно в статусе над калькулятором).

Для проверки серверной функции с реальным окружением: `npm run netlify:dev` — требуется отдельная установка `netlify-cli`, в проект он не входит.

## Публикация

Хостинг — Netlify, конфигурация в `netlify.toml`. Каталог подключается через переменную окружения `CATALOG_CSV_URL`; секреты в коде и репозитории не хранятся.

Сайт опубликован: https://softcare-piskunova.netlify.app/
